# 0004. Наблюдаемость: отдельный сервер, ClickHouse в центре

**Решение.** Сервер `obs`: ClickHouse (логи, метрики, аналитика), Grafana (панели, тревоги), Bugsink (ошибки), Gatus (доступность), Flipt (флаги). Логи и метрики собирает Vector прямо в ClickHouse.

**Почему.** Одно хранилище и SQL на всё — агент разбирает инциденты и считает воронки одними и теми же запросами. Отдельный сервер не отнимает ресурсы у приложений; серверы и GitHub-сторож проверяют друг друга.

**Отличие от плана.** В плане был ClickStack (OTel Collector + HyperDX). В шаблоне логи идут через Vector напрямую: меньше движущихся частей, метки контейнеров Kamal доступны без дополнительной настройки. Трейсы OpenTelemetry и HyperDX как интерфейс — пункт дорожной карты, поверх тех же таблиц.

**Почему не PostHog/OpenPanel для аналитики.** PostHog на своём сервере требует 4 vCPU / 16 ГБ и официально не поддерживается; OpenPanel можно добавить позже, если владелец захочет сам строить воронки в интерфейсе.
