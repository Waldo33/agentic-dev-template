# 0003. Деплой — Kamal 2

**Решение.** Образ собирает и проверяет пайплайн, выкатывает `kamal deploy --skip-push --version=<sha>`.

**Почему.** kamal-proxy даёт бесшовную смену версий (трафик переключается только после `/up`), Let's Encrypt и маршрутизацию по поддомену для многих приложений на одном сервере; `kamal rollback` из коробки. Свой синий/зелёный деплой (как в плане who-is-alive) — много кода на каждое приложение.

**Цена.** Ruby в CI (ставится за ~20 с). Долгие WebSocket-соединения рвутся при смене версии через `drain_timeout` — для реалтайм-игр нужен свой переезд комнат (см. план who-is-alive).
