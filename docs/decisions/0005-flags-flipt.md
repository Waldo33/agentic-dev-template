# 0005. Фича-флаги — Flipt v2 + OpenFeature

**Решение.** Flipt v2 на `obs`, флаги в отдельном git-репозитории; в коде — OpenFeature через `@lab/flags`.

**Почему.** Флаги — YAML в git: агент меняет их коммитом даже без сетевого доступа к серверу, владелец — в панели, история общая. Flipt v2 — один бинарник без базы. OpenFeature позволяет заменить Flipt (например, на GrowthBook для A/B-тестов) без правки приложений.

**Почему не Unleash.** В 2026 ядро перешло на AGPLv3, OSS-версия Unleash Edge получила end-of-life 31.12.2026, значимые функции — в Enterprise.

**Правила.** `release_*` на 100% в production — только владелец; `kill_*` агент может выключить сам при инциденте; старые `release_*` убираются из кода и репозитория флагов.
