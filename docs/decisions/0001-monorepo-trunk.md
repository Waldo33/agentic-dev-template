# 0001. Монорепозиторий и работа прямо в main

**Решение.** Все идеи — папки `apps/<имя>` одного репозитория; push в `main` = прод после зелёных проверок.

**Почему.** Облачная сессия агента привязана к репозиториям и не может сама создать новый — новая идея как папка делается агентом без владельца. Один `AGENTS.md`, одни скиллы и пакеты на всё. Trunk-based — максимум скорости; безопасность дают не ветки, а пайплайн (проверки → e2e → verify → откат) и флаги.

**Цена.** Общий CI на всё (смягчено матрицей затронутых приложений). Выросшую идею можно вынести в свой репозиторий, скопировав `packages/*` и workflow.
