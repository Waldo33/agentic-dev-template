# Репозиторий фича-флагов

Шаблон отдельного приватного репозитория, из которого Flipt v2 читает флаги и куда пишет изменения из панели (`flags.<домен>`). Отдельно от основного, чтобы переключение флага не запускало деплой.

## Как завести

1. Владелец создаёт пустой приватный репозиторий (например `lab-flags`) и fine-grained токен с правом **Contents: Read and write** только на него.
2. В основном репозитории: variable `FLIPT_GIT_REMOTE=https://github.com/<владелец>/lab-flags.git`, secret `FLIPT_GIT_TOKEN`.
3. Агент кладёт в `lab-flags` содержимое этой папки (без README, если не нужен) и запускает `provision.yml`.

## Устройство

- Папка на приложение: `<app>/features.yaml`, `namespace.key` = имя приложения (совпадает с `FLIPT_NAMESPACE` в env приложения).
- Имена флагов — как в `apps/<app>/src/lib/flags.ts`: `release_*`, `kill_*`, `exp_*`, `config_*`.
- Флага нет во Flipt → приложение берёт значение по умолчанию из кода.
- Формат файла — декларативный формат Flipt (`version: "1.4"`). Перед первым использованием сверь с актуальной документацией Flipt v2, поля могли поменяться.

## Кто что меняет

- Агент: создаёт флаги, включает для сегмента владельца, выключает `kill_*` при инциденте — коммитом сюда.
- Владелец: всё, в том числе выкат `release_*` на 100% — в панели Flipt или словом агенту в чате.
